Инструкция по установке конфига / Config Installation Guide

Использование скрипта быстрой установки и сброса INSTALL_DEK0CFG.bat
Русская версия
Шаг 1. Сброс старого конфига и кэша CS2

Запусти скрипт INSTALL_DEK0CFG.bat и выбери пункт 1. Скрипт откроет папку userdata, покажет твой активный Steam ID и после ввода цифр очистит старый кэш (папку 730).

Шаг 2. Автоматическая установка конфига

В главном меню скрипта выбери пункт 2. Скрипт сам найдет CS2 на любых дисках (C:, D:, E:, F:) и автоматически скопирует файл dek0.cfg в нужную папку cfg.

Шаг 3. Включи консоль разработчика

В игре: Настройки → Игра → Включить консоль разработчика → Да.

Шаг 4. Загрузи конфиг в игре

Открой консоль клавишей ~ (тильда) и введи команду: exec dek0.cfg
Нажми Enter — конфиг применится моментально.

Шаг 5 (по желанию). Автозагрузка при запуске

Чтобы конфиг подгружался автоматически при каждом запуске: ПКМ по CS2 в Steam → Свойства → Общие → Параметры запуска и добавь: +exec dek0.cfg

Важные заметки:
  • Файл INSTALL_DEK0CFG.bat берет всю рутину на себя и автоматически находит Steam и CS2.
  • Конфиг dek0.cfg должен лежать в одной папке с батником при запуске автоустановки.
  • Команда активации вводится без пробелов и с расширением: exec dek0.cfg.
English version
Step 1. Reset Old Config and Cache

Run the INSTALL_DEK0CFG.bat script and select option 1. It will open your userdata folder, display your Active Steam ID, and clean up broken CS2 cache (folder 730).

Step 2. Auto-Install Config to CS2

Select option 2 in the main menu. The script will automatically locate your CS2 installation across all drives and copy dek0.cfg directly into the cfg folder.

Step 3. Enable Developer Console

In-game: Settings → Game → Enable Developer Console → Yes.

Step 4. Load Config Manually

Open console using the ~ key and enter: exec dek0.cfg
Press Enter — all settings will be applied instantly.

Step 5 (optional). Auto-load on Launch

To automatically load the config every time you play: Right-click CS2 in Steam → Properties → General → Launch Options and append: +exec dek0.cfg

Important Notes:
  • Using INSTALL_DEK0CFG.bat eliminates the need to manually search for your Steam path or CS2 directory.
  • Make sure dek0.cfg is placed in the same folder as the .bat file before running auto-install.
  • The load command must be typed exactly as shown: exec dek0.cfg.
